# Notebooks

## ARC-AGI-2 Kaggle submit

File: `arc_agi_2_submit.py` (self-contained solver for Code Competition).

### Steps

1. Open [ARC-AGI-2](https://www.kaggle.com/competitions/arc-prize-2026-arc-agi-2/code) → **New Notebook**
2. Add competition data (input)
3. Copy the contents of `arc_agi_2_submit.py` into a notebook cell (or upload as a dataset + `%run`)
4. Run → writes `/kaggle/working/submission.json`
5. **Save Version** → **Submit to Competition**

CLI file upload returned 403 earlier (Code Competition). Notebook path is the supported submit rail.
